# NightGlow Landing Page

Landing page estática para impulsar conversiones con un diseño premium, minimalista y orientado a ventas por WhatsApp.

## Estructura

- `index.html` — estructura principal de la landing page.
- `assets/css/styles.css` — estilos visuales y responsive.
- `assets/js/script.js` — datos de productos, menú, animaciones y FAQ.

## Personalización rápida

1. Cambia el nombre de marca y el enlace de WhatsApp en `index.html`.
2. Ajusta el contenido del catálogo en `assets/js/script.js`.
3. Cambia el tono visual en `assets/css/styles.css` con la paleta negra/turquesa.

## Publicación

Puedes subir la carpeta completa a Netlify, GitHub Pages o cualquier hosting estático gratuito.

## Recomendación

Usa imágenes reales de tus productos y actualiza el contenido de testimonios, garantía y precios antes de publicar.
